# Security Policy

## Supported versions

This is a small plugin; only the latest release on `main` is supported.

## Reporting a vulnerability

Please don't open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/kenny2077/dsh-web-search-zai/security/advisories/new)
instead, or email the owner via the address on the GitHub profile. Include a
reproduction if you can, and give me a heads-up before any public disclosure.
